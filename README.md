# RTS Игра — Дипломный проект 2023

**Важно:** этот проект был разработан мной в качестве студенческого дипломного проекта в 2023 году.

## О проекте

Игра представляет собой стратегию в реальном времени (RTS) с элементами управления ресурсами и строительства базы.  
Игроку предстоит создавать и развивать собственное королевство: строить экономику, усиливать военную мощь и сражаться с другими фракциями.

Боевая система построена на стратегическом размещении войск и грамотном использовании различных типов юнитов для получения преимущества на поле боя.

## Архитектура игры

Основу программной архитектуры составляют два ключевых подхода:

- **Компонентно-ориентированная архитектура** — позволяет разделить различные функции игры на отдельные компоненты, что упрощает разработку и обслуживание. Каждый игровой объект может иметь множество компонентов, которые добавляют новые функции этому объекту.
- **Архитектура MVC (Model-View-Controller)** — разделение приложения на три основных слоя:
  - **Model** — данные и бизнес-логика;
  - **View** — отображение информации пользователю;
  - **Controller** — обработка пользовательского ввода.

Такое сочетание компонентного подхода и паттерна MVC позволило создать гибкую, масштабируемую и удобную в поддержке архитектуру.

## База данных

Для хранения и управления игровыми данными активно используются **ScriptableObjects**.  
Они применяются для описания характеристик зданий, типов войск, исследовательских улучшений, ресурсов и других параметров игры. Такой подход обеспечивает высокую гибкость настройки и удобство работы с данными.

## Основные системы игры

- **SessionsSystem** — управление игровыми сессиями (запуск, завершение, сохранение/загрузка, игровое время).
- **MapSystem** — генерация и управление игровыми картами, обработка событий карты.
- **UnitsSystem** — создание, удаление и управление юнитами, обработка связанных событий.
- **BuildingsSystem** — создание, удаление и управление зданиями, обработка событий зданий.

## User Flow

При первом запуске игрок начинает новую кампанию и проходит серию миссий.  
В каждой миссии необходимо выполнять поставленные задачи, управляя юнитами и зданиями.  
Глобальная цель — выполнить все миссии игры.

При повторном запуске автоматически загружается последнее сохранение.

## Заключение

В рамках дипломной работы была разработана компьютерная игра в средневеково-фэнтезийном сеттинге с использованием **Unity** и **C#**.

В процессе работы были изучены ключевые аспекты разработки RTS-игр: анализ существующих решений, выделение требований, проектирование архитектуры и реализация основных игровых механик.

Проект представляет собой комплексный подход к созданию стратегии в реальном времени и демонстрирует полученные знания и навыки в области разработки компьютерных игр.

**Текущий статус:** бета-версия.  
Реализована часть основных механик. Для доведения игры до полноценного релиза требуется дальнейшая работа по улучшению геймплея и наполнению контентом.
